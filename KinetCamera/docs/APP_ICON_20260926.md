# App 图标(2026-09-26 23:10 双端验收通过)

## 设计语言
- **深空炭黑底**(径向渐变 + 细噪点,拒绝大平面死色):摄影 = 暗房语汇,与 App 内暗色 UI 同一气质
- **品字三摄镜头组**:主摄大(青蓝镀膜)+ 超广角(琥珀)+ 长焦(洋红,错落偏上)——直接呼应产品核心"把几个摄像头都用上"
- 每颗镜头:金属环渐变 → 玻璃深底 → 内环细线 → 紫膜镀膜反光弧 → 内瞳双高光
- **取景框角 + 底部快门条**(亮青 accent):相机语言点题
- 无文字、无 K 字母:图标在 Dock 缩到 16px 仍可辨识(镜头组剪影独特)

## 生成与接线
- 单源脚本 `scripts/gen_icon.swift`(CoreGraphics,1024 母版,可复跑):
  ```
  xcrun swiftc -O -o /tmp/gen_icon scripts/gen_icon.swift && /tmp/gen_icon out.png
  ```
- **macOS**:`KinetCamera/AppIcon.iconset/`(16~1024 全尺寸,sips 缩放 + iconutil 同源)→ Xcode **自动 ConvertIconsetFile 编译成 AppIcon.icns**,Info.plist `CFBundleIconFile=AppIcon`
- **iOS**:`KinetCamera/Assets.xcassets/AppIcon.appiconset/`(单 1024 universal)→ `Assets.car` + `AppIcon60x60@2x.png` 等切片,Info.plist `CFBundleIcons.CFBundlePrimaryIcon.CFBundleIconName=AppIcon`,build setting `ASSETCATALOG_COMPILER_APPICON_NAME=AppIcon`
- project.yml 资源隔离:xcassets 归 iOS target;macOS target 排除 xcassets(iOS 排除 iconset 隐含)

## 踩坑
- **手拷 icns + iconset 并存 = Multiple commands produce**:Xcode 16+ 对 `.iconset` 目录自动编译 icns,再手放一份 `Resources/AppIcon.icns` 就是双产出,BUILD FAILED。正解:只留 iconset 源目录,让 Xcode 编译期产出
- gen_icon.swift 顶层执行代码:文件名必须 main.swift(或去掉 -parse-as-library),否则 "expressions are not allowed at the top level"
- 金属环径向渐变:`drawsBeforeStartLocation` 会留透明外圈,正确画法 = clip 外圆 + `drawsAfterEndLocation` 铺满
