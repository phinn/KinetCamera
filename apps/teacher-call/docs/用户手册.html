0系统概览

1服务器部署

1.1 环境要求

项目要求检查命令
Node.js≥ 18(推荐 20/22)node -v
npm随 Node 自带npm -v
网络教师手机与大屏须能访问服务器 IP同一局域网最简

1.2 三步上线

# ① 进入项目目录(首次会自动装依赖)
cd apps/teacher-call
npm run build

# ② 启动服务(默认端口 3311)
npm start
# ✓ teacher-call server listening on http://0.0.0.0:3311

# ③ 防火墙放行端口(如已开启防火墙)
# CentOS / 麒麟系:
firewall-cmd --add-port=3311/tcp --permanent && firewall-cmd --reload
# Ubuntu / Debian 系:
ufw allow 3311
✓ 验证部署成功

在同一局域网的任意设备浏览器打开 http://<服务器IP>:3311/,出现登录页即部署成功。

1.3 查询服务器 IP

# Linux / macOS
ip addr | grep inet     # 或
ifconfig | grep inet

# Windows
ipconfig

找 192.168.x.x 或 10.x.x.x 开头的内网地址,例如 192.168.1.100。

需求做法

所有数据(账号、班级、呼叫记录)持久化在 server/data/db.json,请勿在服务运行时删除或手工编辑。呼叫记录自动保留最近 500 条。

4常见问题 FAQ

手机提示「大屏未连接」怎么办?

按顺序检查:

① 大屏页是否打开着(浏览器标签页不能关);
② 大屏浏览器地址是否用的同一台服务器 IP;
③ 刷新大屏页面,若配对码变了,旧码已失效 —— 重新生成即可;
④ 仍不通时,在大屏页点 ⚙ 解绑后重新生成配对码。

注:大屏离线时消息仍会记录在呼叫日志中,不会丢失。

语音播报没有声音?

① 检查右上角是否处于 🔇 静音状态;
② 检查大屏设备本身的音量;
③ Chrome / Edge 浏览器支持最好;若页面曾长时间挂后台,点一下屏幕任意位置即可恢复播报(保活机制会自动重试)。

忘记密码 / 需要新增教师账号?

账号数据在服务器 server/data/db.json 的 users 数组中。停止服务后编辑该文件(密码为 SHA-256 值,修改需重新计算),或直接删除 db.json 恢复初始账号。

外网 / 跨网段能访问吗?

系统本身是纯 HTTP + WebSocket,只要网络可达即可。跨公网访问建议:

① 前置 Nginx 反向代理并配置 HTTPS;
② 或使用内网穿透(frp / Tailscale 等);
③ 暴露公网时务必修改默认密码。

学校有多栋教学楼,每块屏都要配对吗?

是,每块大屏各自打开 /screen 生成配对码,一次性操作。发送呼叫时可选择目标大屏;只有一块大屏时无需选择,自动推送。

手机用的过程中换了个网络(如 WiFi 切 4G)会掉线吗?

登录状态基于 cookie,只要新网络仍能访问服务器 IP 就不掉线。跨公网切换(内网 → 外网地址变了)需要重新登录一次。

如何查看呼叫历史?

大屏待机页滚动显示最近呼叫;完整日志(最近 500 条)存在服务器 server/data/db.json 的 callLog 中。

# ── 部署 ──────────────────────────────
npm run build                        # 首次部署:装依赖 + 构建前端
npm start                            # 启动服务(端口 3311)
PORT=8080 npm start                  # 自定义端口

# ── 守护进程(pm2)────────────────────
npm i -g pm2
pm2 start server/index.js --name teacher-call
pm2 save && pm2 startup              # 开机自启
pm2 logs teacher-call                # 看日志
pm2 restart teacher-call             # 重启

# ── 数据 ──────────────────────────────
server/data/db.json                  # 全部数据(账号/班级/日志)
rm server/data/db.json && npm start  # 重置为初始种子数据

# ── 入口 ──────────────────────────────
http://<服务器IP>:3311/              # 手机端
http://<服务器IP>:3311/screen        # 大屏端
