## 排查坑记录(下次直接绕开)
1. **双模拟器抢 17877**:Shot17 与 2CFFB0CA 同时在线,curl 永远打到先启动者;多模拟器场景先 lsof 确认监听 PID 对应哪台
2. **install 后 TCC 失效**:simctl install 会重置授权,顺序必须 install → privacy grant → launch
3. **授权弹窗死锁**:一旦弹窗挂起,privacy grant 不生效(写库但进程内 requestAccess 上下文已死),必须 shutdown 整台模拟器重启
4. **增量编译假成功**:改了源码但产物 mtime 不变,导致"install ok"装的是旧 bundle;每次改代码后核对产物 mtime,必要时 clean build
5. **NSLog 黑洞**:模拟器 app 的 NSLog 进系统日志不可靠,关键路径用文件 trace(NSTemporaryDirectory/kinet_trace.log)
