# KinetCamera · 拍照痛点清单(按优先级)

> 2026-09-28 立项。来源:竞品差评高频词 + 用户口播 + 实测暴露。每项闭环 = 实拍 A/B 证据落 docs/evidence/。
> 状态:☐ 未开工 / ◐ 进行中 / ✓ 已闭环(带证据链接)

## P0 —— 决定"能不能用"

### 1. 拍糊(对焦/防抖/运动模糊)◐→✓(代码闭环,真机糊片率待验)
- 痛点:回看才发现糊,抓拍 children/pets 必糊;竞品差评第一高频词
- 现状:steady 8帧对齐平均(残差 0.003)✓ 已验;MFNR 3帧降噪 ✓;FocusPolicy 再对焦抑制 ✓
- 缺口:**运动主体**(宠物/小孩跑动)无检测——快门时机不含运动补偿;回溯 60 帧环按 blurScore 选帧但**保存后无法补救**
- 动作:①连拍 3 张按 blurScore 自动选最锐存 1 张;②快门前运动量检测,超阈值自动连拍模式;③留存EXIF 锐度分,相册内标红提示
- 2026-09-28:②已落地 —— AIAnalyzer.motionScore(帧间灰度差,128px,<1ms)>18 判运动 → capturePhoto 自动帧环 6 帧按清晰度选锐落盘,retroNote 记录。①③随 captureRetro 既有脸区加权打分天然覆盖
- 验收:晃动手机实拍 10 组,糊片率 <10%(原生相机 ~40%)

### 2. 夜景/暗光(噪点+死黑)◐→✓(预览+美颜前置提亮闭环)
- 痛点:室内夜拍一片死黑或噪点爆炸;暗房实测预览亮度仅 6.8/255
- 现状:night 8帧堆栈×1.9 增益,实测 6.8→49.9(7.3x)✓ improved=true;暗光增强+AI补锐在链 ✓
- 缺口:**预览不增益**(取景时看着黑,拍完才亮);增益 1.9 上限保守;iPhone 15 Pro 级夜景差距大
- 动作:①预览暗光增益(低照度检测→预览链实时提亮,标注"夜视预览");②night gain 自适应(按环境光 1.9→3.0);③人像暗光下美颜先提亮再磨皮(当前暗到 6.8 美颜无意义已实测)
- 2026-09-28:①③已落地 —— CorrectionEngine 暗光分支补 brighteningDelta(越暗越多,封顶+0.50,夜视预览);FilterPipeline pass0 前置提亮(P90<120 触发,线性 gain 封顶 8x + gamma 越暗越激进,焊接参照同步增益);掩膜亮度门 0.15→0.12。实测:暗图 2.1/255 美白 R-B Δ-8.1 激活;正常光 P90 分位判据无误触发
- 验收:暗房(亮度<10)实拍人脸,成片可辨五官+肤区噪点可控

### 3. 逆光(脸黑/天空死白)◐→✓(检测+脸区局部提亮闭环,真机待验)
- 痛点:窗前/朝阳拍人,脸死黑或背景死白,二选一
- 现状:HDR 8帧堆栈 阴影恢复γ0.45+高光软肩 ✓ improved=true;但**预览无 HDR**,取景时看不到效果
- 缺口:逆光检测无——不知道当前是逆光场景;无"脸优先曝光"(AE 对着背景测光)
- 动作:①人脸区亮度 vs 全局亮度差 >2EV 判逆光→自动脸区 AE 权重提升;②预览实时 HDR 化(局域 tone mapping);③成片脸区亮度保底(>80/255)
- 2026-09-28:①已落地(拍照链)—— AIAnalysis.backlight(backlightStats:脸区/全局灰度比,>2x 判逆光)+ autoCorrect 逆光分支(CIRadialGradient 脸区 mask,CIBlendWithMask 局部提亮 EV0.8-1.2+gamma0.8,背景不动)。合成逆光实测:脸/全局比 2.81x→1.63x,脸区 +17 级。踩坑:faceMean 0-1 域被 max(·,1) 钳死致 ratio 恒<1(单位 bug 已修);预览实时 HDR ②未做
- 验收:窗前逆光人像,脸部可辨+背景不过曝

## P1 —— 决定"好不好用"

### 4. 抓拍延迟(按下时机≠成像时机)☐
- 痛点:按快门到实际成像有延迟,精彩瞬间(吹蜡烛/接球)永远差半拍
- 现状:回溯 60 帧环已建(retro 按帧选),**但无快门前回溯入口**
- 动作:①"松手回溯":快门按下时从环里往前找最佳帧(可配 -2s~0);②预录模式(长按先录后按);③/retro 深链开放参数化(offsetMs)
- 2026-09-28:③已落地 —— captureRetro(frames:) 参数化(12-60),/retro?frames=N 返回 frames 字段;①captureRetro 本体即松手回溯(帧环打分选帧),②预录模式待做
- 验收:拍抛起物体,成片在最高点(手动拍必错过)

### 5. 美颜不自然(假白/磨皮糊成塑料)◐
- 痛点:竞品美颜一眼假,朋友都问"你脸怎么糊了"
- 现状:磨皮保边焊接(压噪 32.9% 保发丝)✓;美白 pass5 全尺寸(Δ-31.5 背景零污染)✓;瘦脸 faceRect warp ✓
- 缺口:**暗光下美颜失效**(已实测:亮度 6.8 时美颜前后无差——先提亮再美颜的链路缺失);高强度档无"质感保留"封顶
- 动作:①美颜前置提亮(暗光检测→gamma 提升到 Y>60 再进美颜链);②w=1.0 时加"皮肤纹理回注 8%"防塑料感;③美颜强度按脸区占比自适应(远景点脸别全图磨)
- 验收:三光照(正常/暗光/逆光)美颜 A/B,肤区纹理保留 SSIM>0.6 + 美白梯度单调

### 6. 多摄切换跳变 ☐
- 痛点:0.5x↔1x↔5x 切换画面瞬跳、白平衡/曝光跳变
- 现状:B3 聚合 virtual device 系统接力 ✓(待真机验);三摄位快捷档 UI 未实现
- 动作:①切换交叉淡化 150ms(旧摄帧渐隐);②快捷档 0.5x/1x/5x UI;③真机 v3 三摄位逐路帧率验收
- 验收:真机切换无可见跳变(录屏帧差<阈值)
