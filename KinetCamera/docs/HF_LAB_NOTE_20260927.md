# 暗光磨皮 hf 反升 · 根因定论(2026-09-27)

## 现象
s=0 vs s=0.7 同帧 A/B:全图高频能量 +30%(16.3→21.2);合成源实拍口径 +4.89。
"磨皮反而加高频"疑似 bug。

## 排查链(四步定案)
1. 空间归因:96% 增量来自边缘区(la>12),平坦区仅 +0.3 → 非噪声回归
2. 上采样替换实验(Lanczos→线性):全图 -1.63/边缘 -12.4,但受控复测发现焊接权重
   wE 分布被改变(边缘全焊回,纹理回归 378%)→ 回滚
3. 量化口径审查:合成源实拍图皮肤区高频地板 0.12,比率口径(562%)在低纹理输入下失真
4. **受控单元实验**(/tmp/hf_probe.swift,512² 阶跃边+±12 均匀噪声):
   - 毛孔噪声压掉 **85%**(行差分 8.03→1.24)
   - 阶跃落差保持 **92%**(139.8→128.4)
   - |d| max=8 = thr 软阈值天花板(σ=2.61→thr=8):|o-g|≤8 保留磨皮基座,>8 按比例焊回

## 定论
**渲染链无 bug**。"hf 反升"是保边磨皮的数学表象:边缘大结构保住(92%),
周围毛孔磨平(85%)→ 边缘-平坦对比度的比值必然上升,lap 能量指标随之上升。
该指标测"纹理总量",不测"视觉质量";真实判据=压噪率×保边率(85%×92%),双优。

## 工程决策
- 不改渲染链。上采样线性替换被否(改变 wE 分布,纹理回归)
- 量化口径修正:美颜 A/B 以「压噪率(平坦区)+保边率(阶跃落差)+SSIM」三元组为准,
  弃用单指标 hf 比率(地板效应);新增受控 harness /tmp/hf_probe.swift 口径入 docs
- 此前 09-26 合格口径(真人样张 1.6→2.2 保留 136%)仍然有效:高纹理输入下比率口径成立
