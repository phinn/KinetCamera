## 二、明确砍掉(写清理由,不做半吊子)

| # | 功能 | 砍掉理由 |
|---|------|---------|
| A | **真·宽动态HDR(多EV括弧)** | 软件EV括弧救不回单次曝光已剪裁的8bit信息(高光过255的数据根本没进文件);macOS 公开 API 无 bracketed RAW。**落地的是"堆栈降噪+阴影恢复+高光软肩"——端侧无RAW时真实可行的HDR,不宣称扩真实动态范围** |
| B | **人像光斑虚化** | 无 LiDAR/双摄深度图的 Mac 上做单目虚化=人像边缘必然撕裂(HN婚纱照事件同款翻车)。拒绝交付垃圾边缘。保留手动光圈模拟(暗角+背景压暗滑杆)作为诚实替代 |
| C | **AI消除/生成式填补** | 端侧生成式填补必然涂抹文字/结构,违背"细节不可撒谎"底线。要消除去专业工具,相机不做魔术 |
