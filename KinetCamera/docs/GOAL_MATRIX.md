## 二、本轮美颜深挖(用户点名补的验收)

**方法**:真人照片(GJHD0892,1378×1772)过与 app 同源编译的 FilterPipeline(Photo 档全链),
对照组:① 原图直出 ② 注入 σ=14 感光噪声图 ③ 全链美颜档(smoothing .7 / whitening .6 / bright .15 / sharpen .25)。

**挖出的真 bug**:pass4/pass4' 的"边缘感知回注"是**噪声直通车**。
- 旧公式 `wEdge = min(1, |hf|/16)`:σ=14 噪声 |hf|≈11 → wEdge≈0.7,**70% 噪声原样回注**
- 实测禁用回注压噪 81%,开回注只剩 6-28% —— **磨皮主力度被回注吃掉,还倒贴放大(残差 8.82→10.47,+19%)**
- 根因:固定 t=16 用"幅度"区分"结构 vs 噪声",暗光高 ISO 噪声幅度全落 t 内=全回

**修复**(自适应软阈值):
- 小域 CPU pass 后用高频残差 MAD×1.4826 估噪声 σ(稳健,发丝不干扰),按降采样率换算全尺寸域 σ
- 回注改软阈值:`wEdge = max(0, |hf| − 1.5σ)/|hf|`——2.5σ 外才回注,σ 自适应(棚拍 σ≈6.5 → thr≈10 保毛孔;暗光 σ≈19 → thr≈29 压噪)

**修复后量化**:
| 指标 | 修复前 | 修复后 |
|---|---|---|
| 灰度标定图压噪(σ14) | 6%(t=16)/ 28%(t=32) | **45%** |
| 真人含噪图高频压制 | 6% | **81%**(40.2→7.7) |
| 干净棚拍图边缘保持(无噪场景) | — | **81%**(不过磨) |
| 含噪像素残差 vs 真值 | 10.47(放大 19%) | 9.40(≈输入水平) |

诚实备注:单帧非盲去噪,"小幅真纹理 vs 噪声"理论上不可完全分离;1.5σ 是压噪/保边平衡点,
干净图边缘保持 81% 说明默认档不过磨。含噪图边缘保持 47% 是噪声污染边缘判定的统计效应,列改进项(频域引导)。

1. **CITemperatureAndTint 全黑**:macOS 27 连 neutral=6500 标准域也输出全黑(harness 铁证 lum 183→0),
   人像色温中性化分支彻底移除,色温修正全走 CIColorMatrix WB gain
2. **曝光方向反判**:旧代码拿质量分 >78 当"过曝"压光(高分=接近理想,语义完全反了),
   白背景正常照片会被 +0.8EV 越提越曝。新增 exposureBias(-1..+1)方向量驱动修正,
   quality 分只做展示/评分。WB gain 从分档(0.18/0.35/0.5,强暖图过校翻转 -26.7)改连续比例式
   min(0.30, |cast|/220),实测四档方向全对

夜景/防抖/HDR 合成回归修复:合成源移动 band(2px/帧)在时域平均运动检测(±2px 搜索窗,SAD 采样
4px 网格)下单帧 SAD 12-17 万,7/8 帧被误弃"运动过猛"。band 改静止,三链路实测全通:
夜景(8帧平均+增益x1.9, cast 48.7→-14) / 防抖(残差 0.006 vs 未对齐 0.007) / HDR(kept8 弃0, exp→94.7)
