# 教师呼叫系统

Vue3 + Express + Socket.io 前后端一体。教师手机登录 → 选年级 → 选班级 → 点学生/老师 → 输入文字 → 推送到教室大屏并语音播报「某某同学,请到老师办公室来」。

## 启动

```bash
cd apps/teacher-call
npm run build    # 首次:装依赖 + 构建前端
npm start        # 启动服务 http://localhost:3311
```

换端口:`PORT=8080 npm start`

## 访问入口

| 端 | 地址 | 用途 |
|---|---|---|
| 手机端 | `http://<本机IP>:3311/` | 教师登录操作(手机/电脑浏览器均可) |
| 大屏端 | `http://<本机IP>:3311/screen` | 教室大屏全屏显示,点「生成本屏配对码」 |

**大屏配对逻辑**:大屏页生成的配对码存在本机 localStorage,之后手机端发出的消息自动推送到该大屏。一个服务可绑多个大屏(每个浏览器一个 code)。

## 默认账号

- `admin / admin123`(管理员)
- `wang / 123456`(教师)

## 数据

- 种子数据:6 个年级 × 每年级 4 班 × 每班 20-24 名学生 + 3-4 名任课老师
- 持久化:`server/data/db.json`(删除即重置)
- 呼叫记录保留最近 500 条,大屏待机时显示最近呼叫

## 大屏功能

- 待机:大时钟 + 日期 + 配对码 + 最近呼叫列表
- 呼叫:全屏大字(姓名 + 班级 + 话术 + 发起人)+ 倒计时进度条,自动回到待机
- 语音:Web Speech API 中文播报,自动重复 3 遍;🔊/🔇 切换静音,↻ 重播上一条,⚙ 解绑重新配对

## 技术栈

- 后端:Express + Socket.io + JSON 文件存储(零数据库依赖)
- 前端:Vue3 + Vue Router + Vite
- 通信:REST + WebSocket 实时推送
